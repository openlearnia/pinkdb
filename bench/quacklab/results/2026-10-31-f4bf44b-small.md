# QuackLab on pinkdb — wave 130 (small)

QuackLab's compiled NYC-taxi workload rendered from `bench/quacklab/plan/nyc_taxi_essential1.json`; pinkdb release binaries versus DuckDB v2.0.0-alpha46057 on the same machine. Wall times are one CLI process per phase (setup / ETL / mart refresh); charts run the widgets both engines executed, per client, through pinkdb-server and DuckDB `quack` (widgets pinkdb cannot parse are listed under *Charts*).
