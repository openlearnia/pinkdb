Extensions

Built extension artifacts from the pinkdb extension repository — search the catalog, inspect metadata, and install one in a pinkdb shell with .install <name>. The catalog is fetched live, cross-origin, from index.json.

Artifacts are immutable and verified by SHA-256 before loading (format v1; see the repository's FORMAT.md). The repository Worker serves the machine endpoints only.
