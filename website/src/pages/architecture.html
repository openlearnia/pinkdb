Architecture

An embedded analytical database: everything runs in-process, on vectors, with zero async in the core.

Query pipeline

one parser

SQL is parsed by a peg-generated grammar; it is the only parser path.

A committed corpus plus a seeded randomized fuzz test pin that valid input parses and invalid input returns a clean Parse error.

Execution model

isolation, honestly

BEGIN..COMMIT runs on a private snapshot with write-conflict detection — snapshot isolation without predicate tracking.

  • Vectors, not rows. A Vector is a typed column chunk plus a validity bitmask (bit set = valid, DuckDB-style). Every operator processes a whole DataChunk (≤2048 rows) per call.
  • Selection vectors. WHERE produces a selection vector (no row copying); Vector::gather applies it downstream.
  • Pull-based operators. Scan, Filter, Project, HashAggregate, HashJoin, Sort, Limit — with typed expression kernels, a sort key arena + top-N, and fused join→aggregate fast paths that avoid row materialization for integer keys.
  • Parallelism. Queries run under a shared read lock (parallel readers, parallel chunks via rayon inside each query); writes take the write lock per statement. BEGIN..COMMIT runs on a private snapshot with write-conflict detection — snapshot isolation without predicate tracking (write-skew is possible).

Design rules

  • Rust edition 2021, zero async, no unsafe in the core. Contained unsafe is confined to pinkdb-ffi (and, later, the extension loader crate).
  • Dependencies stay small: csv + rustyline, plus rayon for parallel execution and peg for the SQL parser. The server crate adds no external dependencies; encryption adds the audited RustCrypto crates aes-gcm + argon2 only when enabled.
  • New capabilities ship as separate workspace crates and/or opt-in cargo features, so the default cargo build stays lean (~2 MB) and links no crypto/TLS/format code. Every wave reports release binary sizes; CI grows a build matrix (default, each feature, each crate) plus a wasm check — the core stays wasm32-compatible and the server is target-gated out of wasm builds.
  • No hand-rolled crypto; audited RustCrypto crates only.
