stays in the browser

Statements and rows never leave this tab. Memory is session-only and forgets everything on reload. IndexedDB and OPFS keep a whole .pink snapshot in this browser's own storage: writes autosave after half a second, and Save writes one immediately. Export downloads the same bytes as pinkdb-playground.pink; Import restores a file into the engine and saves it to the selected persistent storage. The database is the same .pink format the CLI writes.

Ctrl/Cmd + Enter runs everything in the editor one statement per card
