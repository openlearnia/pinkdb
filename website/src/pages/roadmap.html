Roadmap

A summary of the wave tracker as of wave 26 (Oct 2026). The single source of truth is ROADMAP.md in the repository — see it for full evidence per wave.

A wave is done only when cargo build + cargo test + cargo clippy are green (plus the DuckDB differential suite and benchmarks where applicable). The differential suite currently matches 60/60 queries in both parser modes; the test suite is 376 tests without the encryption feature and 412 with it.

Deferred

Not currently scheduled: Parquet read (pinkdb-parquet); JS/wasm, Node-native, and Java bindings.

Packaging principles

  • New capabilities ship as separate workspace crates and/or opt-in cargo features; the default cargo build stays lean (~2 MB) and links no crypto/TLS/format code.
  • Every wave reports per-artifact release binary size; the build matrix covers the default build, each feature, and each crate, plus a wasm check — pinkdb (and pinkdb-parquet) must stay wasm32-compatible, and the server is target-gated out of wasm builds.
  • No hand-rolled crypto; audited RustCrypto crates only.
  • Zero-unsafe holds for the core; contained unsafe is confined to pinkdb-ffi and, later, the extension loader crate.
