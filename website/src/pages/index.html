pinkdb — a mini DuckDB in Rust

In-memory columnar storage, vectorized execution, SQL with joins, aggregates, window functions and CTEs, CSV import, durable .pink files with a write-ahead log, an optional network server, and a C ABI — zero async in the core, zero unsafe outside the FFI crate.

pinkdb ships as a library crate (pinkdb), a CLI REPL (pinkdb-cli, a thin consumer of the library), a network server (pinkdb-server, a separate crate so the core stays lean), and a C ABI (pinkdb-ffi).

Quick start

cargo run -p pinkdb-cli          # debug REPL
cargo build --release -p pinkdb-cli
.import sales.csv sales
SELECT region, AVG(total) FROM sales GROUP BY region ORDER BY 2 DESC;

Status

Waves 0–26 are done: the engine, persistence + WAL, multi-database, the network server, at-rest encryption, and the C ABI. The default cargo build links no crypto, TLS, or format code; optional capabilities ship as features or separate crates.
